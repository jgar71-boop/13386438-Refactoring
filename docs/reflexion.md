# Prompting

La tecnica que se utilizó para este proyecto de refactorización fue la de Prompting de Rol para analisis y detección de problemas del proyecto. Para la refactorizacion se utilizo la de Prompt Chaining.

# Aprendisaje

Se aprendio la configuracion e interaccion con el agente, resolviendo problemas comunes repetitivos en codigo en poco tiempo. Se tiene ventaja y avance significativo contra otros metodos incluso mas complejos. Con esta herramienta se puede entregar odigo mas limpio y de callidad.
